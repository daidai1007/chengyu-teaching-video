# 成语教学视频统一排版（最终版）

- 画布1080×1920，背景RGB（249，250，245），文字RGB（18，18，15）。
- 左、右、顶边距113px，内容宽854px。
- 所有词项按单列从上到下排列，禁止2×2横向宫格。
- 每栏顺序：标题行、释义、固定背景插画、2px分隔线。

标题行固定为：`成语　（拼音）　【中性/褒义/贬义】`。

- Windows 上成语使用`C:\Windows\Fonts\simsun.ttc`宋体，增加1px同色描边实现加粗；其他系统使用 Noto Serif CJK 或同等中文宋体。
- Windows 上拼音和褒贬标注使用`C:\Windows\Fonts\msyhbd.ttc`微软雅黑加粗；其他系统使用 Noto Sans CJK Bold 或同等中文黑体。
- 拼音小写、带声调、音节间空一格，使用中文全角括号。
- 褒贬仅允许【中性】【褒义】【贬义】，统一深墨黑。
- 三部分同一行垂直居中，两个间距均为18px，不得越过右侧安全边距或换行。
- 释义及侧重点使用宋体，格式为`释义原文（侧重具体区别）`。

## 插画、分隔线和溢出

- 插画左边缘113px，宽854px，居中裁切，不拉伸、不留黑边。
- 背景像素级固定，只移动人物、动物或核心物体；主体不得进入文字区域。
- 分隔线为2px深墨黑、长854px，位于插画底部下方11px；最后一栏可省略。
- 长释义先清理空格，再在规定范围内缩小；必要时自然分行；仍无法排入则精简侧重点。
- 成语、拼音和褒贬字号固定，禁止压缩字体宽度。
