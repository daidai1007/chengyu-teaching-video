# 输入格式

将用户输入整理为 UTF-8 JSON：

```json
{
  "items": [
    {
      "idiom": "层出不穷",
      "pinyin": "céng chū bù qióng",
      "sentiment": "中性",
      "meaning": "新技术、新模式、新业态不断涌现（侧重连续出现）"
    },
    {
      "idiom": "此消彼长",
      "pinyin": "cǐ xiāo bǐ zhǎng",
      "sentiment": "中性",
      "meaning": "一方减弱的同时另一方增强（侧重此长彼消）"
    },
    {
      "idiom": "此起彼伏",
      "pinyin": "cǐ qǐ bǐ fú",
      "sentiment": "中性",
      "meaning": "这里起来，那里落下，事物连续交替出现（侧重连续交替）"
    }
  ],
  "questions": [
    {
      "text": "高油价时代，如何节油成为车主们关注的焦点，于是各种节能产品应运而生，汽油清净剂、节油贴、节油丸、省油精等等__________。",
      "answer": "层出不穷"
    },
    {
      "text": "在市场竞争中，传统零售业的衰退与电商平台的崛起呈现__________的态势，消费者偏好变化加速了这一趋势。",
      "answer": "此消彼长"
    },
    {
      "text": "夜色渐浓，江风徐徐。在灯火通明的街道上，叫卖声__________，人们流连在繁华小巷。",
      "answer": "此起彼伏"
    }
  ],
  "output_stem": "成语教学_层出不穷_此消彼长_此起彼伏"
}
```

要求：

- `items` 必须包含两至四个对象，并按视频中从上到下的顺序保存。
- `idiom`、`pinyin`、`sentiment`和`meaning`必须为非空字符串。
- `pinyin`必须小写、带声调符号，音节之间空一格；不要包含括号。
- `sentiment`只能是`中性`、`褒义`或`贬义`。
- `questions` 至少包含一个对象，默认三题。
- `text` 必须保存用户原文；不要自动替换标点或措辞。
- `answer` 可为空；能够唯一判断时补充，否则保留为空。
- `output_stem` 可省略，脚本会依据所有成语生成安全文件名。
